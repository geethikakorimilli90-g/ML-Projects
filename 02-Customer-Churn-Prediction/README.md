# Customer Churn Prediction

## 📌 Project Overview
This project predicts whether a customer is likely to leave a company's service using Machine Learning.

## 🎯 Objective
The main objective is to identify customers who are at risk of churning so that businesses can take appropriate retention actions.

## 📊 Dataset
The project uses the Telco Customer Churn dataset.

The dataset contains customer information such as:

- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Internet Service
- Contract Type
- Payment Method
- Monthly Charges
- Total Charges
- Churn

## ⚙️ Project Workflow

1. Data Loading
2. Data Understanding
3. Data Cleaning
4. Exploratory Data Analysis
5. Feature Encoding
6. Train-Test Split
7. Feature Scaling
8. SMOTE for Class Imbalance
9. Model Training
10. Model Evaluation
11. Hyperparameter Tuning
12. Feature Importance
13. Customer Churn Prediction

## 🤖 Machine Learning Models

- Logistic Regression
- Random Forest Classifier
- Gradient Boosting Classifier

## 📈 Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC Score

## 💡 Key Features

- Customer churn probability prediction
- Customer risk classification
- High, Medium, and Low risk categories
- Feature importance analysis
- Business recommendations for customer retention

## 🚀 Business Impact

The model helps businesses identify high-risk customers and take early retention actions.

Examples of possible actions:

- Special discount offers
- Personalized retention campaigns
- Long-term contract offers
- Customer support improvements
